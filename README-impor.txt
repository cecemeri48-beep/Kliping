CARA MEMASANG 2 KLIPING CONTOH + ADMIN CECE MERI
====================================================

1. Buka file impor-kliping.html di browser (klik dua kali). Perlu internet.
2. Masukkan email & kata sandi akun pengelola situs (yang biasa dipakai
   masuk panel admin). Akun ini tidak disimpan ke mana-mana; hanya dipakai
   untuk satu sesi impor di browser Anda.
3. Periksa email Cece Meri (boleh diganti), lalu klik "Jalankan Impor".
4. Tunggu sampai log menampilkan tanda ✔ di semua langkah.
5. Buka situs — dua kliping baru langsung tampil di Papan Kliping dengan
   status Terbit, dikurasi Cece Meri.

CATATAN
- Aman dijalankan ulang: semua penulisan memakai upsert, jadi tidak dobel.
- Cece Meri dibuat sebagai profil berperan Admin. Agar ia bisa masuk
  sendiri, buatkan akun Auth untuk emailnya di Supabase
  (Authentication -> Users -> Add user), sama seperti akun pengelola lain.
- Gambar kliping tersimpan di bucket gambar-kliping
  (kliping/contoh-17agustus.jpg dan kliping/contoh-ppgd.jpg), ukuran sudah
  dioptimalkan agar tampil sebagai thumbnail saat dibagikan ke WhatsApp.
- File gambar juga disertakan di folder gambar/ bila ingin dipakai ulang.
